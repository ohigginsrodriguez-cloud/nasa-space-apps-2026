# Earth System Trend Detective

Proyecto para el **NASA Space Apps Challenge 2026 — Be An Earth System Trend
Detective!**

La aplicación permitirá seleccionar una variable de ciencias de la Tierra, una
región y un periodo; generará una serie temporal y explicará si existe una
tendencia estadísticamente significativa.

## Estado actual

El repositorio está en la fase de planificación y preparación del MVP. La
estructura, responsabilidades, flujo de GitHub y decisiones iniciales están
documentadas en [`docs/`](docs/).

## Estructura inicial

```text

frontend/      Interfaz, controles y visualizaciones
```
