# Checklist de revisión científica

Usar esta lista antes de marcar una variable como validada o fusionar un
cambio científico.

## Variable y producto

- [ ] La variable tiene una definición clara.
- [ ] El ID interno no depende del nombre de un archivo remoto.
- [ ] El producto y campo remoto están identificados.
- [ ] La fuente es oficial o su uso está documentado.
- [ ] La unidad original está registrada.
- [ ] La unidad mostrada al usuario está registrada.
- [ ] La conversión de unidades, si existe, está probada.

## Tiempo

- [ ] La frecuencia está confirmada.
- [ ] El periodo disponible está confirmado.
- [ ] La agregación temporal está definida.
- [ ] Se documentó el tratamiento de estacionalidad.
- [ ] Se documentó el tratamiento de faltantes.

## Espacio

- [ ] La resolución espacial está confirmada.
- [ ] La cobertura geográfica está confirmada.
- [ ] La agregación espacial está definida.
- [ ] Las regiones de ejemplo tienen geometría reproducible.

## Análisis

- [ ] El método estadístico está documentado.
- [ ] La definición de significancia está documentada.
- [ ] Se distingue tendencia de causalidad.
- [ ] El resultado muestra sus limitaciones.
- [ ] Existe al menos un ejemplo reproducible.
